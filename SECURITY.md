# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities by opening an issue with the `security` label.
Do not disclose potential vulnerabilities publicly until they have been triaged and addressed.

## Supported Versions

Only the latest commit on the `main` branch is supported for security updates.

## Human-in-the-Loop & Traceability

This project models regulated insurance operations with mandatory human approval gates.
Never bypass approval workflows, audit logging, or cryptographic traceability controls.
All agent actions must remain reviewable and reversible by a human operator.
