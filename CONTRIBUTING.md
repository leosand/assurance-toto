# Contributing to assurance-toto

Thank you for contributing to assurance-toto. Please follow these guidelines:

1. **Fork and branch** — create a feature branch from `main`.
2. **Code style** — follow existing TypeScript conventions and project structure.
3. **Tests** — add or update tests for agent behavior, approval gates, and audit logging.
4. **Security** — do not remove or weaken human-in-the-loop, audit, or traceability controls.
5. **Commits** — use clear, imperative commit messages.
6. **Pull requests** — open a PR against `main` with a description of changes and any relevant issue references.
7. **Review** — be responsive to review feedback and CI results.

By contributing, you agree that your contributions are licensed under the Apache License 2.0.
